AI Peer Review System

This project provides an AI-powered peer review system for academic papers.

How to Use

  1. Clone the repository: git clone https://github.com/Peter-awe/TakePeerReviewHome.git
  2. Install dependencies: pip install -r requirements.txt
  3. Run the web interface: python webui.py
  4. Access the interface at http://localhost:7860

Features

  • Multiple AI model support (GPT-4, Claude, Gemini, etc.)
  • PDF paper processing
  • Meta-review generation
